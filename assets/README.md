# Desktop icon

The original local `solidworks.png` was extracted from the installed application
for that machine's launcher. It is proprietary, ignored by Git, and **not
distributed**. Fresh clones use the standard `applications-engineering` icon
name supplied by the desktop theme. No vendor artwork is required to launch.

The unmodified redistributable Selawik family is in `fonts/`, with its OFL
license, source link, and per-file checksums.
